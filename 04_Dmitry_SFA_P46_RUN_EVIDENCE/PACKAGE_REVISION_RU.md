# Редакция комплекта

Задание R1, редакция комплекта H2-RU-CHECK. Адресат и результат разработки сохранены. Дополнительно выверены русские инструкции, порядок запуска и сдачи, явные границы ошибок и проверка разрешённых файлов. Уточнённые проверки входят в этот комплект; используйте именно его целиком. Защищённые исходники принятых зависимостей не изменены. В целевом файле остаётся каркас для вашей реализации.

# Состав возврата
Верните один ZIP с единственной корневой папкой `04_Dmitry_SFA_P46_RUN_EVIDENCE/`. Сохраните защищённые файлы побайтно.

- Реализованный `source/audit_release/command_evidence.py` и содержательные `candidate_tests/test_*.py`.
- `return/IMPLEMENTATION_RU.md`: алгоритм, связь требований с кодом и проверками, ограничения.
- `return/REPORT_RU.md`: точная версия Python, команды, рабочий каталог, фактический исход каждой проверки и ограничения; не приписывать готовность продукта.
- `return/PATCH.diff`: изменения относительно этого каркаса; `return/OUTPUT_SHA256.json` с хешами изменённых/добавленных файлов.
- `return/logs/`: полные stdout/stderr и кодом завершения трёх команд из README; синтетические результаты запрещены.
- `return/INTEGRATION_RU.md`: предложение последовательного подключения и восстановления, без самостоятельной установки.

Не включайте виртуальную среду, кэш, секреты и готовые реализации соседних модулей вместо закреплённых reference. Изменение защищённого контракта или программу запуска проверок не исправляет дефект реализации.

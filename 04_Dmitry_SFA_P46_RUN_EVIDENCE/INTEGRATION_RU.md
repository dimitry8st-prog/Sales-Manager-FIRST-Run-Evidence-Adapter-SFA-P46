# Граница подключения P46

Результат — отдельный компонент с ограниченным данным заданием объёмом. Полная регрессия и приёмка Sales First остаются открытыми.

Целевой путь: `audit_release/command_evidence.py`. На проверенной базе он отсутствует. Перед установкой центральный интегратор снова сверяет рабочие исходники, актуальный реестр, закреплённые области изменений и хеши reference. Соседние принятые модули не редактируются.

Общую сборку один интегратор меняет последовательно после приёмки точного возврата. Он сохраняет исходный перечень файлов, устанавливает только разрешённый новый модуль и необходимые собственные тесты, проверяет фактический путь импорта и затронутые контракты. Для восстановления удаляются только добавленные файл и тесты при совпадении их идентичности с установленной версией; затем сверяется исходный перечень файлов. БД, миграции, службы, активация и отправки этому пакету не нужны.

Пакет не разрешает запуск произвольного плана на рабочей системе. Входные TestCase, описания команд и артефакты предоставляет проверенный контролируемый вызывающий код. Компонент не является песочницей и сам по себе не доказывает доверие к этому коду.

# Обозначения в исходниках и контрактах

API — программный интерфейс: точные имена функций, аргументы и поведение. ABI — закреплённое описание совместимости этого интерфейса. DTO — структура данных с фиксированными полями. Callback — переданная функция обратного вызова. Scope — область данных клиента/кампании/почтового ящика; точный набор полей определён соответствующим контрактом.

`source/` или `solution/` — местоположение целевого кода; конкретный единственный изменяемый модуль назван в README. `reference/` — закреплённые исходники или справочные описания. В P23/P46 часть закреплённых исходников находится рядом с целевым файлом в `source/` и также защищена. Справочные описания старых компонентов не являются поручением переписать их: результат этого задания определён корневым CONTRACT_RU.md либо TASK_RU.md.

PASS — проверка прошла; FAIL — проверка не прошла; NOT_RUN — проверка не выполнялась. MISSING_IMPLEMENTATION/IMPLEMENTATION_REQUIRED означают отсутствие реализации в исходном каркасе, а не успешное завершение. Точные имена полей, функций, кодов ошибок и статусов в исходниках сохраняются без перевода, потому что они проверяются программно.
